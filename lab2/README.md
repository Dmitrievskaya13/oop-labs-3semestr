## Лабораторная работа №2 — Простое наследование

Иерархия из трёх уровней: `Тара` → `Ящик` → `Ящик для бутылок`.

Демонстрируется:
- порядок вызова конструкторов (от базового к производному) и деструкторов (в обратном порядке);
- переопределение метода `info()` на каждом уровне;
- явный вызов `Tara::info()`, `Box::info()`, `BottleBox::info()`.
