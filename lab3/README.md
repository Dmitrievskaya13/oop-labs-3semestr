## Лабораторная работа №3 — Виртуальные функции

Базовый класс `Тара` сделан абстрактным: метод `info()` — чисто виртуальный (`= 0`), деструктор — виртуальный.

Производные классы: `Ящик`, `Ящик для бутылок`, `Цистерна`.

Демонстрируется полиморфизм: один указатель `Tara*` поочерёдно указывает на объекты разных классов, и при вызове `info()` выполняется версия, 
соответствующая фактическому типу объекта. Виртуальный деструктор обеспечивает корректное удаление.
