# Лабораторная работа №1 — ООП

**Тема:** Исследование отличий между структурным и объектным подходом  
**Дисциплина:** Объектно-ориентированное программирование  


## Что это

Две реализации одной задачи — учёт маршрутов — для сравнения структурного
и объектно-ориентированного подходов.

Данные о маршруте: номер, начальный пункт, конечный пункт, стоимость проезда,
время в пути. Функциональность: ввод, вывод, поиск маршрута по конечному пункту.
