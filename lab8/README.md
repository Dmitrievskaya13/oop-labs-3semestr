## Лабораторная работа №8 — ООП
## Тема: Исследование средств управления потоками ввода-вывода. Исследование механизма обработки исключений
Дисциплина: Объектно-ориентированное программирование

Что это
Программа из двух частей. Вариант 24: класс «прямоугольный треугольник» — поля a, b (катеты) и color (цвет); площадь считается по формуле S = 0,5 × a × b, результат выводится в 19 позициях с точностью 5 знаков, пробелы заменяются на « } », выравнивание по правому краю.

Часть 1 — потоки ввода/вывода:

заполнение полей класса данными с клавиатуры;

форматирование результата через флаги/методы/манипуляторы (width, precision, fill, setf, setw, setprecision, setfill).

Часть 2 — исключения:

после ввода каждого поля проверяется состояние потока (!cin) и корректность данных (положительное число);

при ошибке генерируется исключение (throw);

обработка через try/catch с несколькими обработчиками.

Демонстрация: тестовые примеры с корректным вводом и с ошибочным (нечисловой ввод, отрицательный катет) — показывается перехват исключений и продолжение работы программы.##
