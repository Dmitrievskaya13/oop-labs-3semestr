## Лабораторная работа №6 — ООП
# Тема: Исследование перегрузки операторов
Дисциплина: Объектно-ориентированное программирование

Что это
Класс route (вариант 24): номер маршрута, начальный пункт, конечный пункт, стоимость проезда, время в пути. Демонстрация перегрузки унарных и бинарных операторов, а также операторов потокового ввода/вывода.

Перегруженные операторы:

! — унарный метод класса, изменяет название конечного пункта;

-- — унарная дружественная функция, уменьшает стоимость проезда на 3%;

-- — бинарный метод класса, разность стоимости проезда двух маршрутов;

-- — бинарная дружественная функция, проверяет, что у обоих маршрутов совпадают начальные и конечные пункты;

<< и >> — вывод в поток и ввод из потока.

Демонстрация: создаются два объекта, на них показывается работа всех перегруженных операторов; ввод/вывод выполняется через перегруженные >> и <<.
