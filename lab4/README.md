## Лабораторная работа №4 — Множественное наследование

Базовые классы: `Spirit` (Дух) и `Human` (Человек).  
Производный класс: `Genie` (Джин) — наследует оба.

Демонстрируется:
- вызов уникальных методов каждого класса;
- переопределение метода `info()`, общего для базовых классов;
- устранение неоднозначности через `Spirit::info()` и `Human::info()`;
- доступ к объекту через указатели `Spirit*` и `Human*`.
