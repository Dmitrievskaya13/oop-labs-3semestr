## Лабораторная работа №7 — ООП
## Тема: Исследование шаблонов функций
Дисциплина: Объектно-ориентированное программирование

Что это
Шаблонные функции для обработки данных разных типов. Вариант 24: сдвиг элементов одномерного массива вправо на n позиций (значение n вводит пользователь). Дополнительно — шаблоны заполнения массива и вывода его элементов на экран.

Функции-шаблоны:

fillArray — заполнение массива;

printArray — вывод элементов массива;

shiftRight — сдвиг массива вправо на n позиций.

Демонстрация: работа проверяется минимум на трёх типах данных — int, double, char.
