# Лаба №5 — Дружественность

**Вариант 24.** Дружественная функция для класса «Джин» (иерархия из лабы №4).

## Что показывает

Дружественная функция `showAllPrivate(const Genie&)`, объявленная другом
сразу трёх классов — `Spirit`, `Human` и `Genie`. Она получает прямой
доступ к закрытым и защищённым полям без геттеров:

| Поле | Класс | Доступ |
|------|-------|--------|
| `color` | Spirit | private |
| `power` | Spirit | protected |
| `name` | Human | private |
| `age` | Human | protected |
| `lampOwner` | Genie | private |
| `home` | Genie | private |

Если бы функция не была friend — компилятор выдал бы ошибку доступа.
